Python pour la sécurité : un journal d'apprentissage

Apprendre Python avec des exemples de sécurité plutôt qu'un « hello world » : un script qui extrait les adresses IPv4 d'un journal, les classe avec le module ipaddress et produit des rapports TXT, JSON et CSV, plus un petit scanner TCP limité à localhost.

Dépôt

Contexte

Presque toutes les offres SOC demandent un peu de scripting. Je publie tout dans un dépôt public, erreurs comprises, pour que la progression reste visible.

Ce que j’ai fait

  • Semaine 1 : bases appliquées aux ports, aux IP et à de faux journaux de connexion, avec pour finir un comptage des échecs de connexion par IP.
  • Semaine 2 : de vrais outils en ligne de commande : sys.argv, fonctions et main(), classification des IP (privées, loopback…), rapports en trois formats, gestion des fichiers manquants.

Ce que ça ne fait pas (encore)

  • Exercices d'apprentissage sur des journaux fictifs, pas un outil de production.
