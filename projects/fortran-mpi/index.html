Parallel programming with Fortran and MPI

From the first MPI_Send to dynamic load balancing: point-to-point exchanges, Scatter/Gather on matrices, and a master–worker scheme that hands 150 Newton-method problems to whichever process is free first.

What I did

  • Fortran basics: checked dynamic allocation, matrix operations, inversion with LAPACK (dgetrf/dgetri).
  • Point-to-point: matrix exchange between two ranks, distributing a matrix read from a file across four ranks with a global error check.
  • Collectives: MPI_Scatter and MPI_Gather to square one matrix per worker.
  • Master–worker: the master sends the next task to the first worker that answers (MPI_ANY_SOURCE) and stops idle workers with a dedicated tag.

Known limits

  • Course exercises: clarity over performance; no speed-up measurements are claimed.
